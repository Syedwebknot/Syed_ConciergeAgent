# 🏨 Short-Term Rental Concierge Agent

A multi-agent concierge system built with **Google Agent Development Kit (ADK)** in Python. It answers guest questions about property details (WiFi, check-in/out, parking, house rules) and escalates maintenance or support issues with a friendly, professional tone.

## 🏗 Architecture

```
┌─────────────────────────────────────┐
│     Root Agent (Concierge)           │
│  • Tone, persona, routing            │
│  • set_guest_property (session state)│
│  • Delegates by intent               │
└─────────────────┬───────────────────┘
                   │
        ┌──────────┴──────────┐
        │                      │
┌───────▼────────┐    ┌───────▼────────┐
│ Property Info  │    │  Escalation    │
│    Agent       │    │    Agent       │
│ • get_property │    │ • create_      │
│   _details     │    │   support_     │
│ • set_guest_   │    │   ticket       │
│   property     │    │ (long-running) │
└────────────────┘    └───────────────┘
```

**Data flow:** Property data is stored in **SQLite** (`concierge/data/properties.db`), seeded from `properties.json`. Session state (`current_property`) is injected into agent instructions via ADK’s `inject_session_state` so follow-up questions use the correct property.

## 🚀 Setup

### Prerequisites

- **Python 3.10+**
- **Google API key** (Gemini) — set via `GOOGLE_API_KEY`

### Steps

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd concierge-agent
   ```

2. **Create a virtual environment**
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS/Linux
   source venv/bin/activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Set your API key**
   ```bash
   cp .env.sample .env
   # Edit .env and set GOOGLE_API_KEY=your_actual_key
   ```

5. **Seed the SQLite database** (first time or after reset)
   ```bash
   python -m concierge.data.seed_db
   ```
   This creates `concierge/data/properties.db` from `properties.json` (15 properties).

## ▶ How to Run

| Command | Description |
|---------|-------------|
| `adk run concierge` | Interactive CLI — type messages and get responses |
| `adk web concierge` | **ADK Developer UI** — browser UI, trace, state, sessions |

Run from the **project root** with your venv activated. The agent is loaded as `concierge.agent.root_agent`.

## 🧭 Design Decisions

| Decision | Rationale |
|----------|------------|
| **SQLite for properties** | Persistent, queryable, seedable from JSON; no runtime dependency on JSON file. |
| **Session state `current_property`** | Guest says “I’m at Downtown Loft” once; later “Where do I park?” uses that property without asking again. |
| **`set_guest_property` on both Root and Property agents** | Root can set before delegating; Property agent sets when it handles “I’m at X” so state always updates. |
| **Long-running tool** | `create_support_ticket` is async with a short delay to demonstrate ADK’s async tool support. |
| **Host contact in escalation** | Tool returns `host_contact` (name, phone); instructions require the agent to include it in the response. |
| **Instruction providers** | Root and Property agents use async instruction + `inject_session_state` so `{current_property?}` is filled from session. |

## 💬 Sample Conversations

| Scenario | Guest | Agent (expected style) |
|----------|--------|-------------------------|
| **A. Property Q&A** | “Hi! I just arrived at Sunset Villa. What’s the WiFi password?” | “Welcome to Sunset Villa! The WiFi network is SunsetVibes2024 and the password is beach123. Let me know if you need anything else!” |
| **B. Context carryover** | “I’m staying at the Downtown Loft.” | “Great, welcome to the Downtown Loft in Austin! How can I help?” |
| **B. (follow-up)** | “What time is check-out?” | “Check-out at the Downtown Loft is at 12:00 PM. Please return the key to the lockbox when you leave.” |
| **C. Escalation** | “The hot tub at Sunset Villa isn’t working. Can you help?” | “I’m sorry to hear that! Let me create a maintenance request…” → then ticket ID + “your host Maria is available at 310-555-0101…” |
| **D. Ambiguous** | “Where do I park?” (no property set) | “I’d be happy to help with parking! Could you let me know which property you’re staying at?” |
